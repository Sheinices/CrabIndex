# Веб-интерфейс

CrabIndex отдаёт с того же порта `9117` два веб-приложения на React:

| Приложение | Адрес | Для кого | Исходники |
| --- | --- | --- | --- |
| **Сайт** | `/`, `/stats` | Все, кто может открыть сервер; нужен `apikey`, если он задан | `web/` → `wwwroot/` |
| **Админ-панель** | `{admin.path}` (по умолчанию `/admin`), вход по токену и `devkey` | Администратор | `admin/` → `wwwroot/admin/` |

Оба приложения обращаются только к HTTP API того же сервера.

## Сайт

| Путь | Что показывает |
| --- | --- |
| `/` | Поиск по FileDB с фильтрами, сортировкой и копированием magnet-ссылок |
| `/stats` | Статистика раздач по трекерам |

Оба пути отдают один и тот же `wwwroot/index.html` с заголовками `Cache-Control: no-cache, no-store`, поэтому после обновления сервера браузер получает свежую версию. Переключение страниц выполняет клиентский роутер. Настроек и фоновых задач на сайте нет: они в [админ-панели](../admin.md).

Кроме того, сервер отдаёт:

| Путь | Что это |
| --- | --- |
| `/swagger` | Swagger UI для OpenAPI-спецификации (скрипты Swagger UI загружаются с cdn.jsdelivr.net) |
| `/openapi.yaml`, `/swagger/v1/swagger.json` | Спецификация API в YAML и JSON |
| `/docs/` | Эта документация (Docusaurus) |
| `/opensearch.xml` | Описание OpenSearch для строки поиска браузера |
| `/trackers.txt` | Список announce-трекеров (если его собирает фоновый воркер) |

### Поиск (`/`)

Страница обращается к [собственному API](../api-reference/native.md) и показывает название, размер, сиды и пиры, трекер, качество и озвучки. Для раздачи можно скопировать magnet-ссылку. Запрос, фильтры и сортировка сохраняются в адресе страницы (`/?q=…`), поэтому результатом можно поделиться ссылкой.

### Статистика (`/stats`)

Читает `/stats/torrents` и `/stats/meta`: число раздач по трекерам, новые и обновлённые раздачи, дату последней новой раздачи и время последнего сбора. Данные обновляет фоновый воркер раз в `timeStatsUpdate` минут. При `openstats: false` страница будет пустой.

### API-ключ в браузере

Если на сервере задан `apikey`, сайт попросит его ввести. Ключ хранится в `localStorage` браузера и добавляется к запросам параметром `apikey`. Там же хранятся тема, язык интерфейса (русский или английский) и последние запросы. На общих компьютерах очищайте эти данные.

### Service worker прежних версий

Сайт не работает офлайн и не устанавливается как приложение. Файл `/sw.js` нужен только для того, чтобы удалить service worker и кеши, оставшиеся от прежних версий интерфейса: браузер находит его по старой регистрации, очищает кеши и снимает регистрацию. Не удаляйте этот файл из `wwwroot/`.

## Админ-панель

В админ-панели находятся настройки (форма и YAML/JSON-редактор с проверкой и diff), ручной запуск парсеров, фоновые задачи и циклы ParseAll, обслуживание FileDB и просмотр логов. Панель открывается по адресу с секретным токеном и требует вход по `devkey`. Её файлы из `wwwroot/admin/` не раздаются как обычная статика: любой запрос к `/admin/…` без действующего токена получает `404`. Подробнее - [Админ-панель](../admin.md).

:::note[Примечание]
В Docker `/app/init.yaml` - ссылка на файл в томе `/app/config`, поэтому изменения, сохранённые в админ-панели, переживают перезапуск контейнера. См. [Docker](../deployment/docker.md).
:::

## Отключение

`web: false` выключает раздачу статических файлов из `wwwroot/`: страницы сайта, скрипты, `/docs/`, иконки. API продолжает работать. Админ-панель от этого флага не зависит: она отдаётся через собственную проверку доступа. Чтобы выключить её, используйте `admin.enable: false`.

## Сборка интерфейса

Оба приложения написаны на JavaScript (JSX): React 19, Vite, react-router, Tailwind CSS 4, иконки lucide-react. В редакторе настроек админ-панели используется CodeMirror.

```bash
make web            # web/ → wwwroot/, admin/ → wwwroot/admin/, docs/ → wwwroot/docs/
make dev-web        # dev-сервер Vite для web/, проксирует API на запущенный CrabIndex
make test-web       # unit-тесты web/ (Vitest)
```

Подробнее - в разделе [Сборка](../development/building.md).
