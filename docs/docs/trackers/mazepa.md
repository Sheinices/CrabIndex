# Mazepa

![](/img/trackers/mazepa.ico)

Mazepa (slug `mazepa`) - украинский форум-трекер на phpBB, около 51 тыс. раздач: фильмы, сериалы, мультфильмы, аниме и документальное (27 разделов). Для скачивания `.torrent` нужен аккаунт.

Каждый запуск `parse` проходит **все** страницы всех разделов подряд (по 50 тем), пока не встретит пустую или повторяющуюся страницу. Для новых раздач и раздач с изменённым заголовком скачивается `.torrent` (`dl.php?id=<id>`) и из него строится магнет-ссылка **без трекеров**: announce-адреса Mazepa содержат личный passkey, поэтому они вырезаются.

## Параметры по умолчанию

| Параметр | Значение |
| --- | --- |
| Блок в `init.yaml` | `Mazepa` |
| `host` | `https://mazepa.to` (пустой `host` - трекер выключен, `parse` отвечает `disabled`) |
| `alias` | не используется |
| `reqMinute` / `parseDelay` | не используются: пауза 800 мс между страницами раздела |
| `useproxy` | не используется |
| Авторизация | обязательна: `login.u` / `login.p` (статический `cookie` не поддерживается) |
| Кодировка | UTF-8 |
| Магнет-ссылки | из скачанного `.torrent`, без трекеров (только DHT) |
| Учитывает `disable_trackers` | нет |

## Конфигурация

```yaml
Mazepa:
  host: https://mazepa.to
  log: true
  login:
    u: "your_login"
    p: "your_password"
```

CrabIndex отправляет форму `login.php` и хранит полученные cookie (`bb_*`) в памяти 2 часа, после чего логинится снова. После рестарта вход выполняется заново при первом `parse`.

## Cron-маршруты

| Маршрут | Параметры | Ответ | Описание |
| --- | --- | --- | --- |
| `/cron/mazepa/parse` | нет | `ok N` (N - число новых раздач), `login error`, `disabled` или `work` | Синхронный полный обход всех разделов |

Маршрут принимает `GET` и `POST`, путь регистронезависим.

## Рекомендуемое расписание

```crontab
# Полный обход форума занимает ~27 минут - раз в 2 часа
25 */2 * * *  /opt/crabindex/Data/run-job.sh mazepa-parse http://127.0.0.1:9117/cron/mazepa/parse 2400
```

Ежечасный запуск накладывался сам на себя, поэтому интервал - 2 часа, а `max_time` у curl - 2400 с. Если предыдущий обход ещё идёт, новый вызов сразу вернёт `work`.

## Файлы в Data/temp

Mazepa не хранит состояния в `Data/temp`: карты страниц нет, каждый запуск проходит разделы с начала.

## Особенности и ограничения

- Нет задач `UpdateTasksParse` / `ParseAllTask`: полный обход выполняется каждым `parse`.
- Раздачи с неизменённым заголовком и уже сохранённым магнетом не скачиваются повторно - повторные обходы дешевле первого.
- Без логина или с неверным паролем `parse` возвращает `login error`.
- Магнет-ссылки без трекеров находят пиров только через DHT/PEX.
- Даты «Сьогодні» / «Вчора» и украинские названия месяцев разбираются автоматически.

## Диагностика

```bash
curl "http://127.0.0.1:9117/cron/mazepa/parse"
tail -f Data/log/mazepa.log
```

В логе видно `Login OK`, `Parsing forum <id> (page N)`, `Found X topics, added Y` и итог `Finished: N in …`.
