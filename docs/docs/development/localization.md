# Переводы и языки

Интерфейс CrabIndex состоит из двух отдельных частей, и переводятся они по-разному:

- **Админ-панель** — свой лёгкий механизм языковых пакетов. Встроены русский и английский, любой другой язык можно добавить **без пересборки**, положив файл на сервер.
- **Документация** (этот сайт) — штатный i18n [Docusaurus](https://docusaurus.io/docs/i18n/introduction).

## Админ-панель

### Встроенные языки

Русский (`ru`) и английский (`en`) вкомпилированы в панель. Русский — базовый: в нём определены все ключи, а любые строки, которых нет в другом языке, показываются по-русски. Файлы: `admin/src/lang/ru.js`, `admin/src/lang/en.js`, реестр — `admin/src/lang/meta.js`.

Язык выбирается переключателем внизу боковой панели; выбор запоминается в браузере. По умолчанию берётся язык браузера, иначе русский.

### Добавить свой язык (без пересборки)

Положите файл `Data/lang/<код>.json` рядом с базой (папка создаётся автоматически при старте). Имя файла — код языка (`de`, `uk`, `fr`, …). Формат — плоский JSON «ключ → строка»; специальный ключ `_name` задаёт название языка в переключателе:

```json title="Data/lang/de.json"
{
  "_name": "Deutsch",
  "nav_overview": "Übersicht",
  "nav_trackers": "Tracker",
  "nav_settings": "Einstellungen",
  "logout": "Abmelden"
}
```

Панель забирает такие пакеты запросом `GET /api/lang` при загрузке и накладывает их поверх встроенных языков. Не нужно переводить все ключи сразу — недостающие строки покажутся по-русски. После добавления/изменения файла просто перезагрузите страницу панели.

За основу удобно взять `admin/src/lang/ru.js` — это полный список ключей.

### Добавить язык в сборку

Если язык должен идти «из коробки», добавьте `admin/src/lang/<код>.js` (по образцу `en.js`), пропишите его в `admin/src/lang/meta.js` и пересоберите панель (`npm run build` в `admin/`).

## Документация

Сайт использует i18n Docusaurus. Язык по умолчанию — русский (`i18n.defaultLocale` в `docs/docusaurus.config.js`). Чтобы добавить, например, английский:

1. Добавьте локаль в конфиг:

   ```js title="docs/docusaurus.config.js"
   i18n: {
     defaultLocale: 'ru',
     locales: ['ru', 'en'],
   },
   ```

   Переключатель языков в шапке появляется автоматически, как только локалей больше одной.

2. Сгенерируйте заготовки переводов интерфейса темы:

   ```bash
   cd docs
   npm run write-translations -- --locale en
   ```

3. Переведите контент. Markdown-страницы копируются и переводятся в
   `docs/i18n/en/docusaurus-plugin-content-docs/current/`, строки интерфейса — в
   `docs/i18n/en/code.json`.

4. Проверьте локаль локально:

   ```bash
   npm run start -- --locale en
   ```

Сборка `npm run build` собирает все перечисленные локали сразу. Подробнее — в [документации Docusaurus по i18n](https://docusaurus.io/docs/i18n/tutorial).
