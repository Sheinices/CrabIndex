# Идентификация: /api/v1.0/conf

`/api/v1.0/conf` - публичный discovery-эндпоинт. Клиент вызывает его при подключении, чтобы убедиться, что по адресу работает совместимый индексатор, узнать, нужен ли API-ключ, и проверить свой ключ до обращения к защищённым маршрутам.

## GET /api/v1.0/conf

Маршрут принимает любой HTTP-метод и не требует ключей: `apikey` здесь только проверяется, но не обязателен. Сам ключ сервера в ответе не возвращается.

### Параметры

| Параметр | Где | Описание |
| --- | --- | --- |
| `apikey` | query | Проверяемый ключ. Пробелы по краям отбрасываются |
| `X-Api-Key` | заголовок | Альтернатива query-параметру |
| `Authorization: Bearer <key>` | заголовок | Ещё одна альтернатива |

Непустой `?apikey=` имеет приоритет над заголовками.

### Пример

```bash
curl "http://127.0.0.1:9117/api/v1.0/conf?apikey=YOUR_API_KEY"

curl -H "X-Api-Key: YOUR_API_KEY" "http://127.0.0.1:9117/api/v1.0/conf"
```

```json
{
  "jacred": true,
  "configured": true,
  "apikey": true,
  "version": "0.1.0"
}
```

### Поля ответа

| Поле | Тип | Описание |
| --- | --- | --- |
| `jacred` | boolean | Всегда `true`. Маркер «это индексатор FileDB». Имя поля сохранено ради совместимости с клиентами (Lampa и её плагины, другие Jackett-клиенты), которые проверяют именно его |
| `configured` | boolean | `true`, если в конфиге задан непустой `apikey` |
| `apikey` | boolean | `true`, если ключ не требуется или переданный ключ совпал с `apikey` сервера |
| `version` | string | Версия сборки CrabIndex, то же значение, что в [`/version`](health.md#get-version) |

## Как читать ответ

| `configured` | `apikey` | Значение |
| --- | --- | --- |
| `false` | `true` | Ключ на сервере не задан, поиск открыт |
| `true` | `true` | Переданный ключ верен |
| `true` | `false` | Ключ не передан или неверен: поисковые маршруты ответят `401` |

Комбинации `configured: false` + `apikey: false` не бывает.

:::note[Примечание]
С неверным ключом эндпоинт всё равно отвечает `200` и меняет только поле `apikey`. Отказ `401` придёт позже, от защищённых маршрутов.
:::

Для проверки живости процесса используйте [Health](health.md), правила передачи ключей описаны в [Матрице доступа](../operations/access-matrix.md).
